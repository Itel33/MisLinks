# Jesus Itel Montenegro — Links

Sitio personal de enlaces, creado con HTML y CSS, sin dependencias ni proceso de compilación.

## Estructura

```text
.
├── assets/
│   ├── hotrack-icon.png
│   ├── spotify-icon.png
│   └── vsco-icon-white.png
├── index.html
├── .gitignore
└── README.md
```

## Uso local

Abre `index.html` en un navegador. Las tarjetas cargan algunas imágenes desde servicios externos, por lo que esas imágenes requieren conexión a internet.

## Publicar en GitHub Pages

Sube el contenido de este proyecto a un repositorio y, en **Settings → Pages**, selecciona la rama principal y la carpeta raíz (`/`). GitHub Pages publicará `index.html` directamente.
